## Home was a library of folders

The legacy homepage was built on the same logic as the Library: sections of folders, stacked one after another. It looked dated, and the way you built it made little sense. To add a section you scrolled all the way to the bottom of the page, and each section had its own settings menu for featured items, columns and scrolling. Every change also went live immediately. So admins weren't updating their homepages often, unless they were being intentional about it.

## Edit mode: build the page where you see it

Edit mode turns the homepage into the editor. Every section offers the same four ways to add content: write a note that lives only on the homepage, add something from the Library, upload new content, or add a widget that updates on its own. The Add menu sits inside each section, so you add things right where they'll appear instead of scrolling to the bottom. Good UI is built into every option, so admins never have to worry about how the page will look.

---

## Emphasis, one item at a time

In the legacy product, a section's settings applied to everything in it. In Edit mode, admins can set the emphasis of a single item. Hovering a card shows small, medium and large display options: medium spans two-thirds of the section and large spans its full width, with the other items reflowing around it. The card's Edit button opens its display options, so it can be shown as an embed or a link.

## Preview content without leaving the homepage

People can open content right on the homepage instead of navigating away. A note opens in place to read in full, and admins can edit it from that same view.

## Changes without the commitment

In the legacy product, every change went live the moment you made it. In Edit mode, changes stay a draft. Admins can rearrange the whole page from one panel, preview it, and publish only when they're ready. That's when the homepage updates for everyone.
